# Проверка прав для первого релиза

Проверка от 2026-11-13 охватывает исходники и предполагаемый Windows x64 ZIP
для GitHub Releases. Действующие статусы записаны в [реестре](review-register.json).

## DoomGeneric (`DG-VERSION`)

Шесть файлов совпадают с зафиксированной upstream-ревизией по данным
[пофайловой сверки](../engine-provenance.json). Их роль в текущей поставке
определена по [списку C-исходников](../../build.rs), директивам `#include` и
списку каталогов для архива.

| Файлы | Роль в поставке |
| --- | --- |
| `doomgeneric.c`, `dummy.c` | Входят в список компилируемых C-исходников. Первый содержит инициализацию движка и буфера, второй — заглушки; в `dummy.c` указан Florian. |
| `config.h`, `doomgeneric.h` | Включаются движком или C-мостом. `config.h` содержит сгенерированные настройки; `doomgeneric.h` объявляет интерфейс платформы. |
| `doom.h`, `mus2mid.h` | Входят в исходный архив; текущая сборка их не включает. В `doom.h` указан Florian. |

У ревизии `e257a09527062bfb986b6e5e0780839b6cbd5b71` в корне лежит текст GPLv2.
В README этой ревизии нет отдельного указания версии для этих файлов.
GPLv2 §9 различает случаи с заданной версией и без неё. Для применения этого
положения к каждому спорному файлу нужно сначала установить, какое лицензионное
уведомление на него распространяется. Заголовки соседних файлов и метка GitHub
сами по себе этого не устанавливают. [LICENSE в этой ревизии](https://github.com/ozkl/doomgeneric/blob/e257a09527062bfb986b6e5e0780839b6cbd5b71/LICENSE) · [README в этой ревизии](https://github.com/ozkl/doomgeneric/blob/e257a09527062bfb986b6e5e0780839b6cbd5b71/README.md) · [GPLv2 §9](https://www.gnu.org/licenses/old-licenses/gpl-2.0.html#SEC9)

Следующее действие — запросить у сопровождающего историю происхождения и точные
условия для этой ревизии. Для вкладов, которыми он не распоряжается, нужен
первоисточник, подтверждение соответствующего правообладателя или заключение с
обоснованием применимой лицензии. Удаление двух неиспользуемых заголовков сократит
состав будущего архива, но не решит вопрос четырёх файлов сборки. При публикации
существующей истории Git эти заголовки всё равно останутся в ранних коммитах.

## Названия и оформление (`PRESENTATION`)

Для оценки выпуска нужны фактические материалы, которые увидит пользователь:
название MCDU DOOM в [README](../../README.md), окно и меню трея, названия
совместимого оборудования, внешний вид экранов и [галерея](../screenshots.md).
В галерее заявлены кадры Freedoom Phase 1 и отрисованные страницы MCDU; для кадров,
шрифтов и шаблонов записаны отдельные источники и уведомления. В записи
`MODIFICATIONS.md` от 2026-10-30 в коммите `a6a6e8d` указано, что Blocks и жест
его запуска исключены. В текущих README, коде и галерее отдельного упоминания
Blocks не найдено. Для проверки прав на оформление нужно сверить окончательный
состав релиза с этим описанием. [Уведомления для изображений](../images/LICENSE.md) · [Источники компонентов](../../THIRD_PARTY.md)

## Владелец и договоры (`OWNER-CONTRACTS`)

У видимых локальных коммитов одно отображаемое имя автора. История Git не
устанавливает, кто вправе распоряжаться оригинальными вкладами и какие договоры
относятся к работе. Владелец выпуска должен подтвердить применимые юрисдикции,
полномочия на публикацию, публичный контакт и наличие относящихся к проекту
условий работодателя, заказчика или поставщика оборудования. В реестр достаточно
внести проверяемое резюме решения без публикации частных договоров и переписки.

## Windows-пакет (`BINARY-SOURCE`)

Текущий формат привязывает portable ZIP к `source-offline` по SHA-256.
`source-offline` включает исходники хоста и движка, `Cargo.lock`, локальные копии
зависимостей, исходники шрифтов и генератор. В Windows-трее есть пункт с
уведомлением о лицензии, гарантии и соответствующих исходниках. Для финального
пакета ещё нужно сверить фактически слинкованные компоненты и внешние библиотеки,
проверить доступ к точному архиву исходников рядом с EXE и оценить применимость
требований к интерактивным уведомлениям и Installation Information. Срок хранения
артефактов Actions сам по себе не обеспечивает доступ к исходникам через страницу
релиза. Комплектация · [Уведомление в трее](../../src/desktop/tray/windows.rs) · [GPLv3 §§1, 5, 6](https://www.gnu.org/licenses/gpl-3.0.en.html)

Техническая проверка от 2026-11-13: `scripts/rebuild-offline.ps1` проверил
`mcdu-doom-0.1.0-source-offline.zip` с SHA-256
`ae8c291853b538117464c8f6a741813f60f598e311a83f1f5e3e4ce40f0936b9`, собрал оба
Windows x64 EXE без сети с пустым `CARGO_HOME` и получил `mcdu-doom 0.1.0`
из пересобранного CLI. Архив подготовлен из рабочего дерева с `dirty: true`.
Этот результат относится к указанному архиву. Для финального коммита проверку
нужно повторить с соответствующим ему архивом.
