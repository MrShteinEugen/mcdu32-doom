# Third-party components

## DoomGeneric

Source: https://github.com/ozkl/doomgeneric, revision
`e257a09527062bfb986b6e5e0780839b6cbd5b71` (2026-10-11).
The selected C source and header files are vendored under `vendor/doomgeneric`.
The revision was recovered on 2026-10-20 by matching all 178 pristine downloaded
files against upstream; 171 vendored files still match and eight are host
modifications/additions. [Per-file hashes and comparison](docs/engine-provenance.json).
Builds use checked-in sources and do not fetch a moving branch.
Most original engine headers grant GPL-2.0-or-later. `sha1.c` is GnuPG code,
Copyright (C) 1998–2001 Free Software Foundation, Inc., under GPL-3.0-or-later.
The upstream root LICENSE contains GPLv2; six small/generated files do not have
individual version grants (`config.h`, `doom.h`, `doomgeneric.c`,
`doomgeneric.h`, `dummy.c`, `mus2mid.h`). Their project-level notice and version
interpretation remain explicit review items; no new per-file grant is invented.
See the [dated audit](docs/legal-review-2026-10-20.md). The new host is GPL-3.0-only.

Host changes: `i_system.c` routes shutdown and fatal engine errors to the
without sound, DEHACKED, or multiplayer. The Rust host never concurrently enters
the engine and does not unwind Rust stack frames using `longjmp`.

Display/UI changes: `r_defs.h`, `r_things.c` and `r_main.c` expose clipped sprite
ownership; `hu_lib.c` and `m_menu.c` export message/menu text; `d_main.c` resets
the text frame and enforces the full gameplay viewport. `mcdu_text.h` includes
the host ABI from `src/doom_bridge.h`. Engine game rules are otherwise retained.

## Freedoom

Downloaded from the project's official release:
https://github.com/freedoom/freedoom/releases/tag/v0.13.0
Release archive: `freedoom-0.13.0.zip`.
Local files under `data/freedoom-0.13.0` retain the release's `COPYING.txt` and
credits. Game data is not embedded in the executable and is ignored by Git.
`scripts/setup-freedoom.ps1` pins the release archive SHA-256 to
`3f9b264f3e3ce503b4fb7f6bdcb1f419d93c7b546f4df3e874dd878db9688f59`, as published
in the release's `freedoom-0.13.0-CHECKSUM`. The script also checks Phase 1's IWAD.
Screenshots in `docs/images/` are generated using this release; the Freedoom
notice and contributor credits are preserved in `assets/freedoom-LICENSE.txt`
and `assets/freedoom-CREDITS.txt`.
Their [image-specific notice](docs/images/LICENSE.md) distinguishes BSD game
artwork from new presentation and GPL font-derived portions. Generation metadata
and hashes accompany the images; none is a commercial DOOM screenshot.

The WINCTRL X-Plane plugin was consulted for protocol research; its source is
not compiled into or required by this project. The compact bank serializer
independently implements the observed record/chunk format and follows the
researched resizer's piecewise descriptor-address interpolation, which remains
opaque in meaning, although tight 11x14 uploads have been checked on hardware.
Full-LCD erasure uses the observed BLACK background command from
ProductFMC::showBackground in the same reference (including its variant byte).
The reference checkout is GPLv3; the new application release is licensed
GPL-3.0-only conservatively. No proprietary SimAppPro executable, aircraft
database or firmware image is included. GPL text is retained in LICENSES.
Reference source: https://github.com/rswilem/winctrl-xplane-plugin, by Ramon
(@rswilem) and the project's contributors. The local research snapshot is excluded
from publication; the host serializer and changes are included in source.
The three-byte and two-byte row variants and the
grid initialization alternatives are documented in `docs/grid-probe.md`.
Universal raster forms are
generated by this project's Rust code. Portraits are derived at runtime from
the WAD selected by the user.

## FlyByWire page references and fonts

Page labels and placement in `src/mcdu/layout.rs` follow FlyByWire MCDU legacy
templates at aircraft revision `76db0aef132fd9698fd4013e2d7239c517dd284e`.
Template portions: copyright (c) 2021-2023, 2025 FlyByWire Simulations, GPLv3.
Our Rust state machine stores local inputs; no navigation database or simulator
flight logic is bundled. HoneywellMCDU and HoneywellMCDUSmall, copyright (c) 2021
Tyler Knox, are distributed under that upstream repository's GPLv3 license.
`assets/aircraft-font/` includes the original FontForge sources, TTF files,
license and provenance. `scripts/build-aircraft-font.py` regenerates the embedded
23 × 29 monochrome bitmap banks. See its NOTICE.md for upstream source links.

The Rust dependency graph and its original license texts are inventoried and
collected by `scripts/prepare-publication.ps1`, from locked local Cargo metadata.
The resulting source archive has hashes for its files, not an ownership warranty.

## Windows dependencies and embedded native code

The [checked-in review](docs/licensing/dependencies-windows.json) identifies the
53 resolved Windows packages, registry-archive checksums, features, declared and
selected license alternatives, and every discovered root/nested license notice.
MIT is selected where offered; the Unicode-3.0 obligation in `unicode-ident`
remains mandatory. SPDX-style OR alternatives are not turned into AND duties,
and an AND component is not dropped. All supplied notices are copied even where
an alternative has been selected. Package metadata is not treated as a grant
over every individual file.

`hidapi` 2.6.7's Rust wrapper declares MIT. Its bundled native HIDAPI is compiled
from `etc/hidapi/windows/hid.c` for the current Windows build and offers GPLv3,
BSD-style or original HIDAPI terms; the supplied BSD-3-Clause alternative is
selected for native HIDAPI. Alan Ott / Signal 11 Software and libusb/hidapi
contributor notices are retained. Its `build.rs` has a GPL-3.0-or-later header;
this is an explicit file exception, not silently relabeled MIT. The source-only
archive copies all four native license texts under their original relative paths.
See [native/file exceptions](docs/licensing/native-components.json) and
[HIDAPI's upstream licensing statement](https://github.com/libusb/hidapi/blob/master/LICENSE.txt).

`minifb` 0.29.0's reviewed build script does not compile its native macOS/Posix
sources on Windows. Other targets/features, toolchain/runtime distribution and
complete source for a future binary require their own review. Current package
declarations and captured notice hashes do not constitute that review.

[License policy](LICENSE-POLICY.md), [dated modifications](MODIFICATIONS.md)
and [unresolved review register](docs/licensing/review-register.json) define the
current preparation scope. No dependency source is claimed to be bundled merely
because its license texts or Cargo.lock are present.
